# Nothing to build

A production build (`nite build`, or `dotnet publish -c Release`, which runs it) found nothing to
build: no modules in the islands folder, no `index.html` in the client root and no `entries` in
`nite.json`. It writes an empty manifest, and the published app has no client code.

## How to fix it

Usually the build is looking in the wrong place:

- Check `clientRoot` and `islands` in `nite.json` against where your files are.
- Run the build from the folder that holds `nite.json`, or point it there with `nite build --dir <folder>`.
- Check that the files are part of the published project and not excluded.

If the project really has no client code yet, the warning is harmless.
