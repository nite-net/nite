# Module not listed in entries

A page loaded a module with `<nite-module src="...">` (or `INiteAssets.GetModuleAsync`) that is
not in the `entries` list in `nite.json`.

In development this works: the dev server compiles any module in the client root on request. A
production build only builds islands, `index.html` and the modules listed in `entries`, so the
same page in production fails with "Module '...' is not in the Nite build".

## How to fix it

Add the module to `entries` in `nite.json`, as a path relative to the client root:

```json
{
  "entries": ["pages/checkout.ts"]
}
```

NiteFx logs this once per module while the app runs.
